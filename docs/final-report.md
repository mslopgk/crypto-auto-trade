# 최종 개발·검증 보고서

날짜: 2026-07-08 · 세션: Claude Code ultracode (병렬 멀티에이전트)

## 1. 무엇을 만들었나

GUI 기반 암호화폐 실시간 자동매매 프로그램. Python 3.12 + PySide6 + pyqtgraph + ccxt + numpy/numba.

- 백테스트 엔진(자체 개발, numba): 봉마감 신호 → **다음봉 시가 체결**, 편도 수수료+슬리피지, 인트라바 손절/익절/ATR 트레일링(손절 우선·갭은 시가 체결의 비관적 가정), 365일 연환산. 계약 위반(룩어헤드)을 테스트로 상시 감시.
- 전략 zoo 9종 + 파라미터 그리드, 레지스트리 등록제로 GUI/옵티마이저 자동 연동.
- 대량 탐색(멀티프로세스) → 게이트 → **롤링 워크포워드**(12개월 IS/3개월 OOS, 플래토-센터 파라미터 선택) → 역변동성·상관 페널티 앙상블 → **180일 홀드아웃 1회 평가** 파이프라인 전체 자동화.
- 라이브 엔진: 페이퍼(기본)/실거래(ccxt), 정밀도·최소주문 처리, 타임아웃 시 clientOrderId 리컨실, 지수 백오프, 상태 영속화·재시작 복구, 리스크 오버레이(일손실·DD 킬스위치).
- GUI 5탭(대시보드/백테스트/최적화/실시간 매매/로그), 다크 테마, 실시간 차트.

## 2. 데이터

- Binance USDT 8심볼 × 15m/1h/4h/1d, 2019-01 ~ 2026-07 (BTC 15m 263,230봉)
- Upbit KRW 4심볼 × 1h/4h/1d (상장일부터; SOL/KRW는 2021-10 상장)
- 파케이 캐시. Upbit 특이사항 처리: 상장 전 since 요청 시 빈 응답 → `to` 후방 페이지네이션, 무거래 캔들 생략 → 플랫 봉 합성.

## 3. 탐색·검증 깔때기

| 단계 | 수량 | 기준 |
|---|---|---|
| 라운드1 그리드 탐색 | 4,176 조합 | 2019~2026 (홀드아웃 180일 제외) |
| 게이트 통과 | 168 | 거래≥30, 샤프≥0.8, MDD≤35%, PF≥1.15 |
| 워크포워드 검증 대상 | 22 셀 | 전략×심볼×TF |
| WFA 생존 | 10 셀 | OOS 샤프≥~0.9, WFE≥0.5, MDD 허용범위 |

**WFA에서 탈락한 것들(정직한 결과):** donchian_single(폴드별 재최적화 불안정 → IS 성과는 피크픽킹), larry_vb(비용 반영 후 무의미), bb_rsi_meanrev(거래수 부족), 4h donchian_multi(OOS 붕괴). 리서치 브리프의 예측("일봉 MR 기각", "생 MACD 기각")과 일치.

**과적합 방지 장치:** 홀드아웃 사전 격리, 폴드별 재최적화(파라미터 고정 성과가 아니라 *선택 프로세스*를 검증), 플래토-센터 선택(피크 회피), 파라미터 안정성 측정, 샤프>3·PF>4 과적합 알람.

## 4. 최종 앙상블 (config/ensemble.json)

10개 셀: TSMOM 1d 7셀(BTC/ETH/SOL/ADA × Binance·Upbit) + EMA크로스 3셀(binance BTC 1d, upbit BTC/ETH 4h). 역변동성 가중, 상관>0.7 페널티, 셀당 35% 상한. 배포 파라미터는 홀드아웃 직전 365일 창의 플래토-센터로 선정(워크포워드 폴드와 동일한 규칙 → 검증된 프로세스 그대로 배포).

## 5. 성과

**워크포워드 OOS(5년, 전 레짐):** 멤버 셀 OOS 샤프 0.97~1.78, WFE 0.53~1.07, 스티치 MDD 16~44%.

**홀드아웃(2026-01-08~07-07 · 급락장):**
- 앙상블: **-4.0%, MDD 5.9%, 연변동성 7.1%**
- 동일 심볼 단순보유: **-39.2%**, MDD 37~66% (BTC -30%, ETH -43%, ADA -54%)

해석: 롱온리 추세 시스템은 하락장에서 수익을 낼 수 없고(공매도 없음), "빠져나와서 지키는 것"이 정확한 설계 목표. 추세 필터·볼타게팅이 작동해 시장 대비 +35%p. 상승장 수익 능력은 WFA 폴드(2021 강세장, 2024 ETF 랠리 포함)에서 검증됨.
